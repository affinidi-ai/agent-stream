# Diagrams

Illustrations used across the repository documentation. They are taken from the Agent
Stream pages of the [hosted documentation](https://docs.affinidi.com/products/affinidi-trust-fabric/agent-stream/)
so that the same pictures explain the product in both places.

Files named `screenshot-*` are dashboard screenshots copied from the hosted documentation,
some cropped to the part of the dashboard a document describes. `screenshot-<topic>-*` files
belong to the document of that topic.
The rest are rendered from diagrams the hosted site draws in SVG, HTML, and CSS, in its dark
theme, captured at twice their display size. `runtime-architecture.png` is the diagram on
the hosted overview page, and `request-pipeline.png` is the one on the pipeline and stages
page.

Each was checked against the source before being adopted. When a hosted diagram or
screenshot changes, re-check it against the code before replacing the copy here.
